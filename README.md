## About

I enjoy turning ideas into small, useful, and deployable products. My recent work focuses on:

- **AI & LLM** — experimenting with OpenAI-compatible APIs, memory systems, and applied machine learning
- **Backend & systems** — Go services, storage engines, proxies, performance practice, and distributed components
- **Web & edge** — TypeScript/JavaScript products, Cloudflare Workers/Pages, Docker, and static-first deployment
- **Native tools** — Swift and macOS development with a focus on fast, keyboard-first experiences
